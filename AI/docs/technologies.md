Používaný technologický stack pro tento projekt zahrnuje:

Frontend:
- React: Hlavní knihovna pro tvorbu uživatelského rozhraní.
- Redux: Pro správu stavu aplikace.
- Axios: Pro komunikaci s backendem a odesílání HTTP požadavků.
- React Router: Pro navigaci mezi různými stránkami a komponentami.

Backend:
- Java Spring Boot: Hlavní framework pro vývoj backendu.
- Spring Security: Pro implementaci autentizace a autorizace.
- Spring Data JPA: Pro práci s databází a správu datových entit.
- Hibernate: Pro ORM (Object-Relational Mapping) a správu databázových operací.
- PostgreSQL: Pro ukládání dat a správu databáze.
- JWT (JSON Web Tokens): Pro zabezpečení a správu autentizace uživatelů.
- Maven: Pro správu závislostí a buildování projektu.
- JUnit: Pro psaní a spouštění testů backendu.
- Postman: Pro testování API a ověřování správnosti backendových endpointů.
- Swagger: Pro dokumentaci a testování API endpointů.
- Docker: Pro kontejnerizaci aplikace a usnadnění nasazení.
- Git: Pro správu verzí a spolupráci na kódu.
